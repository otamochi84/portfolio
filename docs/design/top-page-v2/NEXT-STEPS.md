## 完了したこと

### 構成の変更（2026-08-04〜05）

**Worksの意味を変えた。** 「個別の実績一覧」から「**活動カテゴリ3枚のカード**」へ。

理由: 案件ごとにサムネイル画像を作るのが運用の負担だった。カテゴリ3枚なら画像は3回作れば済み、作り込む余裕もできる。あわせて、Notionのことしか書いていなかったServiceの文脈のなさも解消した。

```
トップ
 ├ Hero / About / Journal
 ├ Works … 活動カテゴリ3枚のカード（画像＋タイトル、枠つき）
 │   ├ /works/notion → Notionでやっていること ＋ 実績一覧（テキスト）
 │   ├ /works/nara   → 奈良の地域での活動
 │   └ /works/gose   → 御所（公開OFF。着手後にONにする）
 └ Contact
実績詳細  /projects/[slug]
/service  廃止（本文はNotionカテゴリのページ本文へ移設済み）
```

### Worksカードの表現

「額縁の中で絵が揺れている」形。**枠は静止し、中の画像だけがそよぎ続ける。**

- 枠: `1px solid #e5e7eb` ＋ 全周12pxの余白、`overflow: hidden`
- 揺れ: `@keyframes wcardImageSway`。最大1.3°／2.8s／無限ループ、支点は画像の上端中央
- **サインカーブを21点（5%刻み）で刻み `linear` で繋いでいる。** 粗いキーフレーム＋`ease-in-out` だと、タイミング関数が各区間に個別に適用されて境目ごとに減速→停止→加速が起き、カクついて見えるため
- `will-change: transform` はホバー中だけ（常時だとカード数ぶんの合成レイヤーを確保してメモリを食う）
- `@media (hover: hover)` 内。`prefers-reduced-motion: reduce` で無効化

キービジュアルの風鈴からインスピレーションを得たが、**KVは今後差し替える前提なので風鈴そのものに依存する見た目にはしていない**（吊り下げ線などは描かない）。借りたのは「揺れる」動きだけ。

## 残タスク

### 1. 画像の用意（大橋さん作業）

Notion `HP_Works` の3カテゴリに画像が未登録。**3:2（横長）**で用意する。

**Notionのスクショの撮り方**（Notion公式サイトの手法を調査した結果）:
- **画面全体を撮らない。UIの一部だけを切り取る**（全体だと文字が潰れる。一部なら文字が読めて「整った仕組み」が伝わる）
- 撮る前にサイドバーを閉じ、`⌘ +` でズームを上げ、**見せるためのサンプルデータを整える**（実データそのままではなく、埋まったステータス・きれいな日付）
- `⌘ + Shift + 4` → `Space` → クリックでウィンドウ単位（影付き）
- 加工は角丸8〜12px・控えめな影・周りに余白。CleanShot X なら撮影時に自動で付く
- サイト側で `saturate(0.78)` 等のフィルタが掛かるので、**撮影時はやや鮮やかめでよい**

3枚のうちスクショが要るのはNotionの1枚だけ。奈良の地域と御所は写真でよい。

### 2. デプロイ先の環境変数

`NOTION_WORKS_DB_ID=d245a52a-5950-44f0-aabe-22173e1efc1c` の追加が必要。未設定でもビルドは通るが**Worksが0枚になる**。

### 3. Journal の仕組み（方式未決）

**調査結果（2026-08-03 時点）**:
- Instagram Basic Display API は2024年12月4日に完全停止。後継は「Instagram API with Instagram Login」で **Business / Creator アカウント限定**（個人アカウント不可）
- トークンは60日で失効。ただし**Facebookページに紐づけた Page Access Token なら実質無期限**（記事で確認済み。パスワード変更や権限取り消しでは失効する）
- oEmbed は2026年6月15日から**トークン不要・App Review不要**。ただし返るのはInstagram公式スタイルの埋め込みHTMLで、ギャラリービューにはならない

**大橋さんの意向**: 画像主体のギャラリー表示にしたい。Instagram投稿の癖をつけたい。「何が書いてあるのか謎くらいで良い」。

**前提となる作業**: Instagram を Business/Creator に切り替え → Facebookページと連携 → Metaアプリ作成 → トークン取得。

### 4. 細かい改善（優先度低）

- **画像取得に失敗するとNotionのS3署名付きURLにフォールバックする**（全取得処理で共通）。このURLは約1時間で失効するので、時間が経つとリンク切れになる。空文字に倒す方が安全だが、その場合は画像が静かに消える
- `getProjects()` が実績詳細ページで2回呼ばれている（`getStaticPaths` と前後ナビ）。`getStaticPaths` の props に渡せば1回で済む
- トップのカードが現在2枚（御所が公開OFF）だが `repeat(3, 1fr)` 固定なので3列目が空く
- `.link-hover-target` はCSS定義がゼロの死んだクラス。10箇所に付いている
- モバイルではカードが揺れない（ホバーがないため）。スマホでの見せ方は別テーマ
