## 2. 設計が必要（実装前に方式を決める）

### 2-1. About の文章を Notion データベースで管理する

**指示**: Aboutの文章をNotionのDBで管理したい。加えて、**文章を変更しても左右カラムの下端が揃い続ける**ようにしておきたい（今は文字数が変わると崩れうる）。

論点:
- 下端揃えは現状「左カラムの伸縮スペーサー」に依存している。和文・欧文の行数が増減しても破綻しない組み方にする必要がある（例: 左カラムに `min-height` を持たせず、grid の `align-items: stretch` と写真側の伸縮だけで吸収させる／文字数の上限をNotion側で運用ルールとして決める、など）
- 文章の改行位置は現在 `<br>` で固定している。Notion管理にすると改行をどう表現するか決める必要がある（改行をそのまま反映する／段落ごとに分ける）

### 2-2. キービジュアル・Aboutスナップ写真を Notion データベースで管理する

前回提案した内容。既存の `src/lib/notion.ts` の `downloadImage()` が使える（NotionのファイルURLは期限切れするため、ビルド時に `public/notion-images/` へ落として静的配信する。Worksのサムネイルが同じ方式）。

提案した構成:
- Notionに「サイト画像」DBを作る
- プロパティ: `スロット`（select: `hero-kv` / `about-photo`）、`画像`（files）、`代替テキスト`（text）、`公開`（checkbox）
- `notion.ts` に `getSiteImages()` を追加し、スロット名をキーに画像パスを返す
- `index.astro` のプレースホルダ `<div>` を `<img>` に差し替える

**2-1 と 2-2 は同じ「サイトコンテンツDB」にまとめられる可能性がある。** 別々に作るか統合するかを先に決める。
※ Notion側のDB作成前に、必ず Notion内の `NOTION.md`（ページID `e84cafd5-d2df-40d5-9819-d3fc5685c4fd`）を読んで規約に従うこと。
